# Mes artefacts

Site qui regroupe mes artefacts Claude de 2ᵉ année de pharmacie, rangés par matière : cours expliqués, cartes, fiches, labos interactifs, carnets d'erreurs et outils.

- `index.html` : la page d'accueil (recherche, filtre par type, sections par matière).
- `a/<nom>/` : une copie de chaque artefact.

Les copies sont figées à la date de leur dernière mise à jour. Pour les actualiser, demander à Claude de re-synchroniser le site.
